# Movement resources

The movement maintains a wider set of public-facing projects. These can help readers understand its origins, activities and documentation, but are **movement-produced sources** and should be labelled accordingly.

| Resource | Purpose |
|---|---|
| Protest history and demands | Background, milestones and changing demands |
| Protest map | Locations and dates of events, subject to source checks |
| Flamingo Dossier | Collected documents and investigations; review claims individually |
| Flamingo Times | Movement publications and commentary |
| Referendum initiative | Proposed civic action concerning Law 21/2024 |
| Diaspora activity | Reports of events outside Albania |
| Community ideas and draft laws | Proposals, not enacted legislation |
| Protest pulse | Movement's own activity tracking |

Open the [official project directory](https://www.flamingorevolution.eu/) for the current links. For external audiences, cite a project's specific document or source rather than relying on a project title alone.
