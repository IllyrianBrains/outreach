## Suggested workflow

1. Add the organization and a publicly listed professional contact.
2. Confirm the correct country, language and form of address.
3. Recheck every factual statement and link immediately before sending.
4. Record the send date and set a follow-up date (normally 3–5 working days later).
5. Log replies, corrections, refusals and requests not to be contacted again.
6. Do not place private personal data, sensitive victim details or non-public addresses in this shared table.

### Status key

- **Translation ready:** relevant language pack exists but still needs recipient-specific editing and language review.
- **Partial:** some, but not all, locally useful languages are available.
- **To translate:** only the English source is currently available.
- **Contacted:** use only after adding a dated entry to the follow-up log.
