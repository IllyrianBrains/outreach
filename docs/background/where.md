# Where did it happen?

The first reported protests took place around Albania's **Vjosë–Nartë coastal landscape**:

- Akërni / Pishë Poro–Narta
- Narta Lagoon
- Zvërnec

Demonstrations later spread to **Tirana**, other Albanian cities and Albanian diaspora communities abroad.
